一、

真正的学习需要四样东西

普通 AI 对话通常全部跳过
  1. 路径知道按什么顺序学什么
  2. 测试发现自己其实不懂什么
  3. 压缩需要时 5 分钟能复习完
  4. 反馈漏洞立刻被发现并补上

伴学把这四样东西做成插件：路径写进学习阶梯与计划，测试变成一次一题的考场，压缩落在费曼复述与一页速查表，反馈记在漏洞日志与隔天复测。每个学科一份档案，换天、换对话都能接着学。

二、

能做什么

共 6 题

1学习路径

五级学习阶梯（每级写清应理解什么、精通表现、里程碑和自测），20 小时计划拆成 2 小时一个单元，外加最多 5 个精选资源。

2一次一题的考试

对话出题 → 面板作答 → 回对话评分。难度沿阶梯递增，记录具体漏洞和判分依据，只重讲答错的部分。

3掌握度与复习

计划完成、独立通过、提示后完成、隔天复测分开记录；自动排 +1 / +3 / +7 天复测，到期在面板提醒。

4知识压缩

费曼循环：讲给 agent 听，讲不清的地方被标出来再讲一遍；学完压成一页速查表，考前 5 分钟扫完。

5同堂伴学

跟着网课记笔记：课中标记，「原课要点」与「agent 补充」分栏保存，互动补讲，从错题回溯到课件页与原讲解时间。

6Safari 适配器可选

macOS 上读取课程播放状态，暂停 / 继续 / 定位，同步课件锚点。目前只在雨课堂回放上实测过。

三、

一轮怎么用

对话负责教，面板负责交
💬 DSH 对话 · agent 写档案📋 侧栏「伴学」面板 · 你来看、来答
  1. 新建学科在「概览」填主题、目标、截止时间和可用小时数。
  2. 建阶梯和计划回到对话，让 agent 读取学科、绑定当前对话，写入阶梯与计划，并先带你学第一个单元。
    请用伴学工具读取我刚创建的学科，先通过 study_write 的 bind_session 操作将它绑定到当前对话，再建立学习阶梯和学习计划并写入档案。先带我完成第一个单元，不要一次讲完整套课程。
  3. 开始考试学完一个单元就说「开始考试」，agent 一次只出一道题。
  4. 在考场作答点「提交并继续考试」。面板只保存答案，不自己打分。
  5. 评分、抓漏洞agent 读到答案，给分并指出确切漏洞，讲解后出下一题。
  6. 压缩与复测学完存一页速查表，安排 +1 / +3 / +7 天复测。
  7. 到期提醒「概览」显示到期的复测，输入框下方的挂件显示当前进度。
四、

六张方法卡

面板「方法」页一键复制提示词

学习阶梯

先看清整张地图，再决定今天学哪一级

什么时候用：刚决定学一个主题，或说不清自己现在算哪一级

20 小时计划

先学能带来 80% 效果的 20%，而不是学完所有内容

什么时候用：时间有限、想尽快上手，或计划总是排得太满

考到崩溃

一次一题、每题打分，逼出「不知道」的精确边界

什么时候用：学完一个单元，或「感觉懂了」但讲不出所以然

一页纸小抄

把学到的压成 5 分钟能扫完的复习入口

什么时候用：学完一个单元，或考试、面试、开会前 5 分钟

从噪音里找信号

只留 5 个真正值得投入的资源

什么时候用：开始学之前，或收藏夹满了却迟迟没开始

费曼循环

讲不清，就是还没真懂

什么时候用：学完还觉得不稳，或某个概念总是记不住

五、

安装

三选一

先准备好 DeepSeek Harness

有桌面版直接打开；命令行用户按官方说明启动，默认界面是 http://127.0.0.1:3080：

npx @deepseek-ai/dsh web

先在「设置 → 模型」配置可用模型，再选择或添加工作区。伴学在 DSH 0.2.1-rc.5 上开发和验证；Safari 课程控制需要 macOS，普通学习流程不需要。

  1. DSH 侧栏打开「插件」，点「添加插件」。
  2. 粘贴下面的地址（固定在 v1.0.0）：
    git+https://github.com/zgdllt/study-companion.git#v1.0.0
  3. 点「安装」，完成后点「立即启用」；提示需要重启就重启 DSH。
  4. 刷新界面，侧栏出现「伴学」。插件列表里的包名是 @local/study-companion。

运行 DSH 的那台机器要能访问 GitHub。不用单独构建，也不用把源码复制进 DSH 目录。

  1. 从 Releases 下载 local-study-companion-1.0.0.tgz，不要解压。
  2. 在同一个「添加插件」输入框填这个文件的绝对路径，例如 /absolute/path/to/local-study-companion-1.0.0.tgz。
  3. 安装并启用。

路径必须在运行 DSH 的那台机器上。远程使用 DSH 时，浏览器所在电脑的下载路径不能直接用。

git clone https://github.com/zgdllt/study-companion.git && cd study-companion && pwd

把 pwd 输出的绝对目录填进「添加插件」。目录安装会链接到源码：改了客户端刷新页面即可，改了 Host 按提示重载插件或重启宿主。

开发检查：npm run check（语法）· npm test（Host 46 项 + 课次 34 项回归）· npm pack。

装好了吗？对一下答案

  • 「插件」页里伴学已启用，Host 行没有加载错误
  • 侧栏能打开「伴学」，看到 概览 / 阶梯 / 考场 / 课堂 / 方法
  • 新建学科后，在对话里让 agent 读取档案，能调用 study_read

只有插件条目、没有面板：确认组合包已启用后刷新；有 restart-required 提示就重启 DSH。其他问题请带上 DSH 版本和安装日志提交 Issue。

六、

数据在你自己的机器上

$DSH_HOME/storages/study-companion/
├── active.json          # 当前学科
├── subjects/<id>.json   # 计划、考试、漏洞、掌握度与复测
├── courses/<id>.json    # 课程身份与网址
├── lessons/<id>.json    # 播放状态、锚点、笔记与回溯
└── prefs.json           # 表达偏好
  • 一个学科一份档案，能单独备份和迁移；卸载插件不会删档案。
  • 插件本身没有云端服务或遥测。对话内容按你在 DSH 里配置的模型服务处理。
  • DSH_HOME 未设置时是 ~/.dsh；可在 cordis.patch.yml 里用 config.dataDir 换目录。
七、

老实说

  • 评分是模型对这一次回答的判断，不等于真实能力验收，也替代不了真实项目和反馈。
  • 方法卡引用的研究只支持机制，不承诺「快 10 倍」。「包教包会」是宣传片里的梗：不会就再考，直到会。
  • 自动前测、首单元完整验收、教材边界核验、真实浏览器全链路验收还没完成，以接口契约里的标记为准。
  • 没在其他操作系统和其他 DSH 版本上做过端到端验收。
