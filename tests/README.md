# 回归测试

在仓库根目录运行，无需另装依赖：

```sh
npm run check
npm test
```

`run-all.mjs` 将 Host、Safari 适配器与方法卡复制到临时目录，重建 ESM 测试环境，依次运行两套回归。测试中的 DSH 上下文是模拟对象，数据使用临时目录，不会读取个人学习档案或执行 Safari 控制。

| 套件 | 检查数 | 范围 |
| --- | --- | --- |
| `host-regress.mjs` | 46 | 并发写、出题覆盖防护、题号与答案版本、非法请求、学科归属、主对话绑定、掌握度、拆项评分 |
| `lesson-regress.mjs` | 34 | 能力状态、未知媒体位置、锚点对齐、分栏笔记、生成补讲、偏好合并、学科隔离、课次路由 |

GitHub Actions 在 Node.js 22、24 上执行语法检查、两套回归，并对 `npm pack` 产出的安装包解压后执行相同检查。测试运行器本身使用 Node.js 内置模块。

模拟上下文回归不涵盖真实 DSH 插件加载、浏览器渲染、模型判分质量或实际课程播放。涉及这些路径的改动还需要在对应环境中验收。
